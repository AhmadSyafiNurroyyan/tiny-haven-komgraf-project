# Lisensi Aset

Semua aset pihak ketiga yang dipakai di Tiny Haven dicatat di sini.

## Model 3D

### Kenney Nature Kit
- Sumber: https://kenney.nl/assets/nature-kit
- Pembuat: Kenney (Kenney Vleugels)
- Lisensi: CC0 1.0 Universal (domain publik, atribusi tidak wajib)
- Dipakai pada: `assets/model/nature/*.glb` - pohon, batu, tunggul, tenda, api unggun, bunga, jamur, dan tumpukan kayu

### Tiny Glade (diorama)
- Sumber: https://sketchfab.com/3d-models/tiny-glade-a30d8e3aad714c7fa8582c4ef23835e2
- Pembuat: Shahriar Shahrabi (https://sketchfab.com/shahriyarshahrabi)
- Lisensi: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/)
- Catatan: lisensi ini mewajibkan pencantuman nama pembuat. Hapus bagian ini kalau model tersebut tidak jadi dipakai.

## Font

### Minecraft (teks antarmuka)
- Berkas: `assets/fonts/Minecraft.ttf`
- Dipakai pada: subjudul, tombol, dan keterangan versi
- Catatan: arsip fontnya datang tanpa berkas lisensi, jadi sumber dan ketentuannya belum jelas. Font ini meniru huruf khas game Minecraft, dan nama serta rupa huruf Minecraft adalah milik Mojang Studios. Untuk tugas kuliah yang tidak dikomersialkan, pemakaiannya wajar, tapi catat sumber unduhannya di sini begitu diketahui. Jangan dipakai kalau proyek ini nanti dirilis komersial.

### Magic Light (judul game)
- Sumber: https://www.fontspace.com/magic-light-font-f107354
- Pembuat: Edric Studio (https://edricstudio.com)
- Lisensi: Freeware, Personal Use Only (versi demo)
- Dipakai pada: judul TINY HAVEN di menu utama
- Catatan penting: versi demo ini TIDAK BOLEH dipakai untuk keperluan komersial. Untuk tugas kuliah yang tidak menghasilkan keuntungan, penggunaannya masih sesuai. Kalau game ini nanti dirilis komersial, lisensi penuh harus dibeli lebih dulu di https://edricstudio.com/magic-light-font/
